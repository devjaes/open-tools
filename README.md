# Open Tools

Welcome to the Open Tools collection! This repository is a work-in-progress, designed to host various utility applications built with Python.

## Current Tools

### 🛠️ [Audio/Video Merger](media/audio-video-merge/README.md)
A desktop application for merging video and audio files.
- **Location**: `media/audio-video-merge/`
- **Description**: A GUI-based tool that uses FFmpeg to combine video and audio streams, featuring a real-time progress bar and a clean Tkinter interface.
- **Build Command**: `python build.py` (from the root directory)
- **Output**: `dist/audio-video-merge.exe`
